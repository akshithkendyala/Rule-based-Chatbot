# Rule-based-Chatbot
A simple rule-based chatbot built with Python and NLTK that matches user inputs using predefined patterns and regex. Created as a learning project to understand NLTK, conversational flow, and basic NLP concepts while building strong foundations in chatbot logic.

# A simple chatbot that:

> Responds to greetings (hi / hello / hey)

> Extracts user names dynamically

> Answers basic questions

> Tells jokes

> Provides help based on keywords

> Handles unknown inputs gracefully

> Ends conversations on “bye” or “exit”
